Code

The code, and what each piece does

Four notebooks ran the calculations on Google Colab GPUs. Five small scripts redraw figures, rebuild the tables and recompute the infrared numbers from the released data. Everything is under the MIT licence.

How to reproduce

2 minutes · any computer

1 · Recompute the numbers

Python 3 only; no GPU, account or API key.

python code/analysis/ir_compare.py

Prints 25 bands, scale factor 0.9736, 11.0 cm⁻¹ typical error, largest error 29.2 cm⁻¹, rank correlation 0.86.

10 minutes · any computer

2 · Redraw the vibration figures

Rebuilds the Hessian from the 73 saved force files.

pip install numpy matplotlib ase pillow
FIG_OUT=out python code/figure_scripts/make_hess.py
FIG_OUT=out python code/figure_scripts/make_viz.py
FIG_OUT=out python code/figure_scripts/make_table.py
2 to 3 hours · Colab GPU

3 · Rerun the calculations

Open the four notebooks below in Colab (L4 for Module 1, A100 for Module 2). Needs Skala-1.1 from its developers and a language-model API key for the step-settings calls in Module 1. Results should match within small tolerances, not line for line.

Every data file is listed with its size and SHA-256 in data/MANIFEST.csv. The full step-by-step guide is on Reproduce.

Inside Module 1

  • Optimizer: L-BFGS (ASE) on Skala-1.1 forces from GPU4PySCF, run in passes with a gradient budget.
  • Monitor: code measures each step (step size against the cap, energy trend, curvature) and fires triggers.
  • Safeguards: every change is bounded and logged. A same-structure check guards the hand-off to Module 2.

Not included here. The plotting scripts for the overview and appendix figures are not part of this package. The numbers behind them are all in the data folder. Notebooks for the annulenes and for Modules 3 and 4 are on the main site.
