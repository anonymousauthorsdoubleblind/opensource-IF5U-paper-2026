Reproducible data tables

Every number, in tables

Nineteen tables, each rebuilt from the released data by one script. Every table has a CSV file you can download, open in a spreadsheet and check.

Rebuild all tables. pip install numpy, then python code/analysis/make_tables.py from the repository root. It reads data/, writes the CSV files in tables/, and checks every key file against its SHA-256 in the manifest (53 of 53 match when this page was built). Frequencies rebuilt from the saved force files differ from the published ones by at most 0.01 cm⁻¹. The script uses no fitted or tuned number; the only typed-in values are the three start energies from the paper and the two static tables in section 7.
